# 🚀 快速开始指南

## 前提条件

1. **macOS系统** + **Docker Desktop**
2. ✅ **IBM Informix Client SDK已包含** - 无需额外下载

## 📦 完整包内容

此包已包含所有必需文件：
- IBM Informix Client SDK 4.50.FC12 (76MB)
- 所有配置文件和脚本
- 测试程序和验证工具

## ⚡ 一键安装

```bash
# 1. 解压完整包
tar -xzf Go_ODBC_Informix_Complete_Package.tar.gz

# 2. 进入项目目录
cd Go_ODBC_Informix_Package  

# 3. 运行一键安装脚本
./install.sh
```

## 🧪 测试连接

```bash
# 1. 复制测试文件到容器
docker cp simple_test.go informix-odbc-x86:/home/test/

# 2. 运行测试
docker exec informix-odbc-x86 bash -c "cd /home/test && go run simple_test.go"
```
